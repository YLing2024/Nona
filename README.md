# Nona

一款简洁高效的 AI 聊天客户端，兼容 OpenAI 格式接口，支持多服务商、多模型、多会话管理与 Agent 预设，可自行配置 API Key 接入任意兼容服务商。

## 功能特性

### 对话能力
- **流式输出**：SSE 流式渲染，Markdown 实时渲染，思考内容（reasoning）可展开/收起；滚动跟随策略：仅在停在底部时自动滚动
- **停止生成**：生成中可随时中止（发送键变为停止键 / Esc），停止后保留已生成内容，可一键「继续生成」
- **重新生成 / 编辑重发**：可重新生成最后一条回复；可编辑任意用户消息并重发（自动截断其后消息）
- **消息操作**：复制、删除消息（桌面端悬停显示操作栏，移动端常显）
- **代码块增强**：语法高亮、语言标签、一键复制；支持链接点击跳转与网络图片加载
- **用量统计**：每条回复展示 ↑输入/↓输出 tokens 与耗时（解析接口 usage）
- **多行输入**：输入框最大 6 行，Enter 发送 / Shift+Enter 换行，工具条可直接切换模型、思考强度与流式开关
- **超时与重试**：连接与空闲双超时保护；失败的回复保留内容并可重试

### 会话管理
- 多会话的新建、切换、删除、重命名、置顶、复制与本地持久化；会话标题自动取首条用户消息
- **会话搜索**：按标题与消息内容实时过滤（Ctrl+F 聚焦搜索框）
- **会话分组**：置顶 / 今天 / 昨天 / 更早
- **匿名会话**：完全独立的内存会话，不保存记录、不出现在会话列表中
- **上下文窗口管理**：启发式 token 估算并实时显示用量（如 `≈ 8.4k / 32k`）；可配置上下文上限，超限自动裁剪最早消息并提示
- **导出 / 导入**：单个会话导出为 Markdown / JSON、复制为 Markdown；全部会话 JSON 备份与恢复（设置 → 数据）

### 配置体系
- **多服务商配置**：可添加多个服务商（OpenAI 或任何兼容 OpenAI 格式的第三方），各自独立配置 Base URL 与 API Key；支持调用 `/models` 接口获取模型列表并多选启用
- **模型配置**：全局模型默认值配置页面，可统一设置聊天模型、Agent 模型等默认选项；支持手动输入模型 ID 或通过 `/models` 接口批量拉取并勾选添加
- **Agent 预设**：可配置多个 Agent（名称 + 完整上下文参数），设置默认 Agent 后「新建会话」自动套用；新建时也可从下拉菜单指定 Agent
- **会话上下文**：每个会话可独立配置系统提示词、Temperature、Top P、Max Tokens、Presence/Frequency Penalty、N、Stop、Seed、Response Format、思考强度等 OpenAI 参数，每项带说明（tips）

### 界面与体验
- **现代化 UI**：靛蓝紫设计系统，浅色 / 深色（蓝黑底）/ 跟随系统
- **自适应布局**：宽屏（≥900px）常驻侧边栏，窄屏自动切换为抽屉导航
- **动效细节**：消息入场动画、流式光标、思考过程折叠卡片、回底按钮
- **桌面快捷键**：`Ctrl+N` 新建会话、`Ctrl+F` 搜索、`Esc` 停止生成、`Enter` 发送 / `Shift+Enter` 换行

## 快速开始

```bash
flutter pub get
flutter run
```

1. 打开应用后，点击左下角「设置」→「服务商」
2. 添加服务商：填写名称、Base URL（如 `https://api.openai.com/v1`）与 API Key
3. 点击「获取模型列表」拉取可用模型并勾选启用
4. 回到聊天页即可开始对话（可在输入框上方工具条切换模型）

> 支持任意 OpenAI 兼容接口：修改 Base URL 即可接入 OpenAI、DeepSeek、通义千问等第三方服务商。

## 项目结构

```
lib/
├── main.dart                        # 应用入口
├── theme/                           # 设计系统（靛蓝紫双主题 + 组件主题化）
├── models/                          # 数据模型（消息/会话/上下文/服务商/Agent）
├── services/                        # 业务服务（聊天/存储/配置/导出）
├── screens/                         # 页面（主界面/设置/会话上下文/服务商/Agent/模型配置）
├── utils/                           # 工具（token 估算）
└── widgets/                         # 复用组件（侧边栏/消息流/输入区/代码高亮/添加模型对话框等）
```

## 技术说明

- Flutter + Material 3（靛蓝紫设计系统，浅色/深色双主题）
- 依赖：`http`（API 请求）、`shared_preferences`（本地存储）、`flutter_markdown` + `highlight`（Markdown 渲染与代码高亮）、`url_launcher`（链接跳转）、`file_selector`（导出/导入文件）
- 兼容 OpenAI Chat Completions 与 `/models` 接口格式
- 支持平台：Windows / macOS / Linux / Android / iOS / Web
