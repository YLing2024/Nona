# Nona

一款简洁高效的 AI 聊天客户端，兼容 OpenAI 格式接口，支持多服务商、多模型、多会话管理与 Agent 预设，可自行配置 API Key 接入任意兼容服务商。

## 功能特性

### 对话能力
- **流式输出**：SSE 流式渲染，Markdown 实时渲染，思考内容（reasoning）可展开/收起（折叠时显示最新 5 行）；滚动跟随策略：贴底时持续跟随流式内容，离开底部停止跟随，切换会话时直接定位到最新消息
- **图片输入**：支持选择本地图片（多选，单张 ≤8MB）与粘贴图片链接/Data URL，消息气泡内展示缩略图；多模态请求自动使用 OpenAI `content` 数组格式，上下文用量计入图片 token
- **消息 TTS 朗读**：每条消息可一键「朗读/停止」，调用系统 TTS（支持 Windows / macOS / Android / iOS / Web）
- **自动标题**：在「模型配置」中配置「标题生成模型」后，会话标题由 AI 根据首条消息自动生成；未配置则维持截取首条消息的默认逻辑
- **精确 token 估算**：内置 tiktoken cl100k_base 与 o200k_base 双词表（纯 Dart、离线、按模型自动选择），与 OpenAI 官方逐 token 一致；未加载时回退启发式
- **停止生成**：生成中可随时中止（发送键变为停止键 / Esc），停止后保留已生成内容，可重新生成
- **消息编辑**：用户与 AI 消息均可编辑，点击跳转独立编辑页；AI 消息的「思考内容」与「回复内容」都能修改，保存后就地写回，编辑结果自动进入后续对话上下文
- **回滚到此处**：任意用户消息可一键回滚（二次确认），删除该消息及其后的所有消息，并把内容回填到输入框重新发送
- **重新生成**：可重新生成最后一条回复；失败的回复保留内容并可重试
- **消息操作**：复制、编辑、回滚、重新生成、删除（桌面端悬停显示操作栏，移动端常显）
- **回复标注**：每条 AI 回复头部标注本次使用的服务商与模型（如 `Nona（OpenAI · gpt-4o）`）
- **代码块增强**：语法高亮、语言标签、一键复制；支持链接点击跳转与网络图片加载
- **Markdown 增强**：任务列表复选框、宽表格横向滚动、LaTeX 公式（$...$/$$...$$/\[...\]）、Mermaid 图渲染（流程图/时序图/饼图等，解析失败回退显示源码）
- **用量统计**：每条回复展示 ↑输入/↓输出 tokens 与耗时（解析接口 usage）
- **多行输入**：输入框最大 6 行，Enter 发送 / Shift+Enter 换行，工具条可直接切换模型、思考强度与流式开关
- **超时与重试**：连接与空闲双超时保护；自动重试（连接失败 / 限流 429 / 服务端 5xx 时指数退避，最多 3 次尝试，可在偏好设置关闭）

### 会话管理
- 多会话的新建、切换、删除、重命名、置顶、复制与本地持久化；会话标题自动取首条用户消息
- **会话文件化存储**：桌面/移动端按「索引 + 每会话文件」增量持久化（仅重写变化的会话），写入串行化防并发覆盖；首次启动自动从旧版存储迁移；Web 端保持兼容
- **会话全文搜索**：`Ctrl+F` 打开全屏搜索页，跨全部会话搜索标题与消息内容，关键词高亮、标题命中置顶；点击结果直接跳转定位到对应消息
- **会话分组**：置顶 / 今天 / 昨天 / 更早
- **匿名会话**：完全独立的内存会话，不保存记录、不出现在会话列表中
- **上下文窗口管理**：tiktoken 精确估算并实时显示用量（如 `≈ 8.4k / 32k`）；可配置上下文上限，超限自动裁剪最早消息并提示；**未手动配置上限时自动按模型推断**（内置主流模型上下文窗口库：claude 200k / gemini 1M / deepseek 64k 等，联网能力表同步 LiteLLM 目录）
- **导出 / 导入**：单个会话导出为 Markdown / HTML / PDF / JSON、复制为 Markdown；全部数据 ZIP 备份（会话 + 服务商 + Agent）与恢复；**支持导入 Chatbox / Cherry Studio 备份**，可一键迁移；移动端无系统保存对话框时自动回退写入应用目录；PDF 内置中文字体、自动分页；HTML 导出内嵌图片

### 配置体系
- **多服务商配置**：可添加多个服务商（OpenAI 或任何兼容 OpenAI 格式的第三方），各自独立配置 Base URL 与 API Key；支持调用 `/models` 接口获取模型列表并多选启用
- **多协议支持**：OpenAI / Anthropic（Claude）/ Gemini 原生协议，协议类型按地址自动探测或手动指定；消息格式、请求头、流式解析（含 Claude 思考块、Gemini thought 分离）自动适配
- **自定义请求头/请求体**：每个服务商可配置额外 HTTP 请求头与请求体字段（JSON），发送时合并
- **Prompt 变量**：系统提示词支持 `{cur_date}` `{cur_time}` `{model_id}` `{locale}` `{timezone}` 等动态变量，发送时自动展开
- **模型能力配置**：每个模型可独立配置「多模态 / 推理」能力，支持一键测速（延迟数展示，未测试显示「未测试」，点击可发起测试）；模型名过长自动换行完整展示；删除模型/服务商时联动清理悬空的默认模型配置
- **模型能力映射表**：内置静态映射表（离线兜底）+ 联网更新缓存，按模型 id 自动填充「多模态 / 推理 / 上下文窗口」配置；可手动「从网络更新」，显示精确到秒的更新时间，可开启「启动时自动更新」
- **模型配置**：全局模型默认值配置页面，可统一设置聊天模型、Agent 模型等默认选项
- **Agent 预设**：可配置多个 Agent（名称 + 完整上下文参数 + 长期记忆），设置默认 Agent 后「新建会话」自动套用；新建时也可从下拉菜单指定 Agent
- **会话上下文**：每个会话可独立配置系统提示词、Temperature、Top P、Max Tokens、Presence/Frequency Penalty、N、Stop、Seed、Response Format、思考强度等 OpenAI 参数，每项带说明（tips）
- **TTS 设置**：朗读语速与语言可配置（中/英/日），长文本按句自动分块朗读，朗读中的消息气泡高亮

### 工具与扩展
- **MCP 支持**：配置 MCP 服务（Streamable HTTP / SSE），工具自动注入（function calling），支持工具调用循环（最多 8 轮）、取消传播与内置 fetch 工具
- **Web 搜索**：发送前自动搜索（Bing / DuckDuckGo 免费、Tavily API、SearXNG 自托管），结果注入上下文并标注引用编号
- **文档多模态**：支持附加 PDF / DOCX / TXT / Markdown 文档，自动提取文本随消息发送
- **AI 翻译**：独立翻译页，调用当前默认模型流式翻译，支持 8 种目标语言
- **多模型对比**：同一问题并行发送给多个模型，并排流式对比各模型回答
- **本地知识库**：添加文本文件自动分块，对话时检索相关内容注入上下文（RAG）
- **云同步备份**：备份上传 / 恢复至 WebDAV 或 S3（自写 SigV4 签名），支持云端备份列表与删除
- **服务商分享**：服务商配置一键导出为文本 / 从文本导入（含协议与自定义头）
- **消息分支**：重新生成自动保存旧回复，可一键回退到任一历史版本
- **网络日志**：记录应用内全部网络请求（聊天、测速、拉取模型、能力表更新、MCP 调用等），含请求/响应 Headers、Body 与字节大小；支持持久化（桌面/移动端落盘）、按天分组查看、详情页、全文查看（虚拟化渲染）、JSON 一键格式化、外部编辑器打开；**支持按成功/失败过滤与导出**；可配置最大保留条数（默认无限）

### 界面与体验
- **现代化 UI**：靛蓝紫设计系统，浅色 / 深色（蓝黑底，可选 OLED 纯黑）/ 跟随系统
- **主题定制**：预设色板（靛蓝/紫罗兰/天蓝/青绿/橙/玫红/赤红/青灰）+ 自定义取色器，强调色实时驱动 M3 色板；未自定义时 Android 12+ / iOS 自动跟随系统动态主题色
- **中英双语界面**：完整 i18n（中文 / English），偏好设置可切换语言或跟随系统
- **自适应布局**：宽屏（≥900px）常驻侧边栏，窄屏自动切换为抽屉导航
- **动效细节**：消息入场动画、流式光标、思考过程折叠卡片、回底按钮
- **桌面快捷键**：`Ctrl+N` 新建会话、`Ctrl+F` 全文搜索、`Esc` 停止生成、`Enter` 发送 / `Shift+Enter` 换行（PC/Web 默认，可在偏好设置切换）

## 快速开始

```bash
flutter pub get
flutter run
```

1. 打开应用后，进入「设置」→「服务商」
2. 添加服务商：填写名称、Base URL（如 `https://api.openai.com/v1`）与 API Key
3. 点击「获取模型列表」拉取可用模型并勾选启用
4. 回到聊天页即可开始对话（可在输入框上方工具条切换模型）

> 支持任意 OpenAI 兼容接口：修改 Base URL 即可接入 OpenAI、DeepSeek、通义千问等第三方服务商。
> 开发调试时可在根目录 `.env` 配置 `NONA_DEBUG_API_KEY` / `NONA_DEBUG_BASE_URL`，非 release 构建会自动注入一个内置调试服务商（不污染正式配置）。

## 项目结构

```
lib/
├── main.dart                        # 应用入口（启动恢复/退出冲刷/代理同步等）
├── core/                            # 地基层（禁止依赖 features）
│   ├── database/                    # drift 数据库（24 张表 / v7 schema / DAO / 工厂）
│   │   └── dao/                     # SessionDao / GenerationRunDao（类型安全读写）
│   ├── models/                      # 数据模型（消息/会话/引用/服务商/Agent 等）
│   ├── services/                    # 跨域基础服务（聊天/存储/网络日志/能力映射等）
│   │   ├── chat/                    # 请求执行器 / SSE 解析
│   │   ├── protocol/                # OpenAI / Anthropic / Gemini 协议适配器
│   │   ├── mcp/                     # MCP 客户端 / 审批策略 / 本地工具
│   │   ├── usage/                   # 成本价格表 / 用量统计 / 余额查询
│   │   ├── knowledge/               # 知识库检索器 / embedding 提供者
│   │   ├── memory/                  # 记忆服务（自动提取 / 注入 / 工具）
│   │   ├── export/                  # 备份 / 导入（8 格式）/ 导出（MD/HTML/PDF/JSON）
│   │   ├── sync/                    # WebDAV / S3 云同步
│   │   └── checkpoint_service.dart  # 流式 checkpoint（B-06）
│   ├── network/                     # dio 统一网络层（日志/重试/代理拦截器）
│   └── utils/                       # 工具（token 估算 / checkpoint writer 等）
├── features/                        # 业务域（chat/session/provider/model/agent/mcp/
│                                   #  search/knowledge/memory/world_book/sync/export/
│                                   #  stats/imggen/translator/settings）
├── shared/                          # 跨域复用（路由 / 通用组件）
└── l10n/                            # 本地化（zh/en）
```

## 技术说明

- Flutter + Material 3（靛蓝紫设计系统，浅色/深色双主题，含本地化 zh/en）
- 依赖：`http`（API 请求）、`shared_preferences`（本地存储/Web 兜底）、`flutter_markdown` + `highlight`（Markdown 渲染与代码高亮）、`flutter_math_fork`（LaTeX 公式）、`flutter_tts`（系统 TTS 朗读）、`url_launcher`（链接跳转）、`file_selector`（文件选择）、`path_provider`（会话/日志文件目录）、`flutter_dotenv`（调试环境变量）、`archive`（ZIP 备份）、`dynamic_color`（动态主题色）、`pdf`（PDF 导出）、`sqlite3`（本地数据库，Web 条件隔离）、`flutter_secure_storage`（API Key 加密存储）、`fl_chart`（统计图表）、`math_expressions`（计算器工具）、`cryptography`（OAuth PKCE）
- 兼容 OpenAI Chat Completions 与 `/models` 接口格式；Anthropic Messages 与 Gemini generateContent 原生协议
- 支持平台：Windows / macOS / Linux / Android / iOS / Web（PWA）
- 零服务器约束：所有功能本地可用；模型 API / MCP / embedding 均为用户自配 BYOK 端点
