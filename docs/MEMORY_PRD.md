# Nona 记忆功能 PRD v2

## 〇、设计原则（参考 Hermes 记忆系统）
- 记忆分层：核心记忆（手动/置顶）+ 自动记忆（提取）
- 预算控制：总量/注入/单条三重预算，全部可配置
- 高信号提取：只记偏好/纠正/持久事实，垃圾不记
- 修正优先：用户纠正 → 更新旧条目（不新增）
- 作用域隔离：全局 / Agent 独立记忆空间
- 隐私：本地存储 + 一键清空 + 开关

## 一、记忆体系（两层）
```
核心记忆（手动/置顶）→ 高优先级，始终注入
自动记忆（对话提取）→ 按相关性注入
```

## 二、功能需求

### ① 自动提取（高信号分级）
- P0：用户明确偏好/习惯（"我喜欢/我习惯/请以后"）
- P0：用户纠正（"不对/其实我是"）→ 触发旧记忆更新
- P1：持久身份/事实（职业/地点/常聊领域）
- 不记：闲聊、一次性信息、任务进度、临时状态
- 静默提取不打断对话；每轮提取 ≤3 条

### ② 记忆调用（注入）
- 新会话按相关性检索注入：核心优先，自动次之
- 注入 ≤5 条 且 ≤800 tokens（可配），显示"记忆占用：N 条 / X tokens"
- 注入标注来源，可点击查看原文

### ③ 预算管理（全可配）
| 预算 | 默认 | 超限策略 |
|---|---|---|
| 记忆库总容量 | 200 条 | 提示清理（最久未用→低优先级） |
| 注入 token 预算 | 800/次 | 按相关性截断 |
| 单条长度 | ≤100 字 | 提取精简/拆分 |
| 每轮提取数 | ≤3 条 | 延后 |

### ④ 记忆管理页
- 列表（内容/来源/时间/使用次数/优先级标签）
- 查看/编辑/删除/置顶（转核心）/搜索/标签过滤
- 手动添加（标签：偏好/身份/工作/生活/其他）
- 一键清空（全部/按类型）

### ⑤ 冲突与纠正
- 相似度检测 → 自动合并/更新旧条目（保留历史版本可回溯）
- 用户纠正（反义表达）→ 覆盖旧条目

### ⑥ 开关与作用域
- 全局开关 + 会话级开关 + Agent 级独立记忆空间（memory_<agent_id> / memory_global）

### ⑦ 导出/导入
- JSON 备份（全量/按空间），恢复时预算检查

### ⑧ 隐私
- 本地存储、一键清空、开关关闭即不提取不注入

## 三、数据模型
```
MemorySpace { id, name, type: 'global'|'agent', budgets: {max_items, max_inject_tokens, max_item_chars} }
MemoryEntry {
  id, space_id, content(≤100字), tags[], priority: 'core'|'auto',
  source_session, source_ts, created_at, updated_at, use_count, pinned,
  history: [{content, ts}]
}
存储：沿用会话文件化存储体系（memory_<space>.json 增量持久化）
```

## 四、与现有功能协同
- 记忆注入预算独立于上下文窗口（或可选计入显示）
- Agent 预设可绑定默认记忆空间
- 记忆纳入会话全文搜索（可选）

## 五、风险与对策
1. 误提取 → 高信号分级 + 管理页可删 + 每轮限条
2. token 超支 → 三重预算 + 可视化
3. 隐私 → 本地 + 一键清空 + 开关
4. 记忆失真 → 冲突更新 + 历史版本 + 使用频率统计
